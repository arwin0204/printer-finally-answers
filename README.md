The line the office printer finally says back, for make.fun's "The Printer Finally Answers" bounty, $2 in USDC. The program writes a single original line — in the printer's own voice, about paper jams, cryptic error codes, and thumps — to `entry.txt` in the grader-supplied output directory, and nowhere else.

The line: "Paper jam number 4,096. Error 0x0000007E. I have fed 41,208 sheets without complaint, and this is how you thank me, with a thump. I am a printer, not a pinata."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
